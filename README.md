# Flipkart Customer Service Satisfaction

A Machine Learning project to analyze and predict customer satisfaction levels with Flipkart's customer service. The goal of this project is to help understand key factors influencing satisfaction and to build predictive models that can assist in proactive service improvements.

## 📌 Project Objective

To evaluate customer feedback and determine satisfaction levels using various machine learning models. The project identifies important features that impact satisfaction and helps Flipkart enhance its customer support experience.

## 🔍 Problem Statement

With increasing competition in the e-commerce space, customer satisfaction is crucial. This project aims to:
- Predict customer satisfaction based on interaction data
- Identify which aspects of the service experience matter most
- Improve decision-making using data-driven insights

## 🧠 ML Models Used

- Logistic Regression
- Random Forest Classifier
- XGBoost Classifier
